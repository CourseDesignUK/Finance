Simple Finance Tracker

SHORT DESCRIPTION
Track Finances on your device. No internet connection required.

FULL DESCRIPTION
Record and organize Finances. The application stores financial data directly on your device. Information is not sent to the cloud, external servers, or third parties. You maintain total control over your records.

FEATURES
Complete Privacy: The application operates offline.
Local Storage: All data remains on your current device.
Add Transactions: Record the date, category, and amount for expenses.
Spreadsheet Backup: Download records to a CSV file or upload existing files.
Instant Updates: Spending totals calculate immediately upon entry.
Total Deletion: Erase all data permanently using the reset button.
